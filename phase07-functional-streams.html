7.1 Core Functional Interfaces, Lambdas & Method References

💡 Real-World Analogy: Passing Code as Data
In Java 7, if you wanted to pass a piece of logic (like "how to sort employees"), you had to create an entire class or bulky anonymous inner class just to wrap one method.
With Lambdas (Java 8), you can treat behavior directly as data! You can pass a piece of code (employee -> employee.getSalary() > 50000) straight into a method just like you pass an integer or string.
Interface SAM Descriptor Input & Output Lambda Syntax Real-World Backend Example
Predicate<T> boolean test(T t) Takes T, returns boolean emp -> emp.isActive() Filtering active accounts, validating user inputs
Function<T, R> R apply(T t) Takes T, transforms to R user -> user.toDTO() Entity to DTO mapping in Spring Boot services
Consumer<T> void accept(T t) Takes T, returns void msg -> kafkaProducer.send(msg) Sending events, logging, printing audit trails
Supplier<T> T get() Takes nothing, returns T () -> new OrderNotFoundException() Lazy error generation: repo.findById(id).orElseThrow(...)
📂 Module 2.../Tester1007Predicate.java — Predicate Composition 
package com.accenture.ltt.functional;

import java.util.function.Predicate;

public class Tester1007Predicate {
    public static void main(String[] args) {
        // 1. Define individual reusable validation rules
        Predicate<String> hasMinLength = s -> s.length() >= 8;
        Predicate<String> startsWithAdmin = s -> s.startsWith("ADMIN-");

        // 2. Compose complex business rules using default methods: and(), or(), negate()
        Predicate<String> validAdminId = hasMinLength.and(startsWithAdmin);

        System.out.println("ADMIN-1002 valid? " + validAdminId.test("ADMIN-1002")); // true
        System.out.println("USER-505 valid? " + validAdminId.test("USER-505"));     // false
    }
}
👁 Functional Interface Predicate Composition Breakdown
  • java.util.function.Predicate<T> Represents a boolean-valued function of one argument: T -> boolean. Abstract method is test(T t).
  • Predicate Composition (.and(), .or(), .negate()) Default methods like .and() allow chaining modular validation rules together like Lego bricks without messy nested if blocks.
  • Senior Rule: Reusable Business Rules Define predicates as static constants in your domain services (e.g. IS_ACTIVE_USER, HAS_VALID_KYC) so they can be reused across Stream filters and REST validation endpoints.

7.2 Stream API Pipeline, Laziness & Grouping Collectors

💡 Real-World Analogy: The Assembly Line (Streams are Lazy!)
Imagine an automated car manufacturing conveyor belt.
• Adding filter() is like bolting on a sensor that detects defective car frames.
• Adding map() is like bolting on a robotic arm that sprays red paint on the car.
DOES ANY CAR GET PAINTED YET? NO! The conveyor belt is switched OFF until you press the big green "START" button at the end. That big green button is the Terminal Operation (collect(), reduce(), count()). Once pressed, items flow through in one unified pass!
